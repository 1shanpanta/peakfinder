# peakfinder

Local replica of the PeakFinder iOS app. It labels mountain peaks on a 360 degree panorama.

## Plan

- Terrain: free elevation tiles (Copernicus GLO-30 or SRTM).
- Peak names: OpenStreetMap `natural=peak`, from a Geofabrik extract.
- Core: horizon and viewshed math, then label layout.
- Shell: not chosen yet (web page or Expo).

## Status

Spec stage. No code yet.
